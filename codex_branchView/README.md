# 枝间

本机 Codex 的选词追问与分支阅读界面。普通发送继续当前真实对话；选中文字后，从所属的已完成轮次创建真实 Codex fork。

## 启动

需要 Node.js 24 或更新版本，以及已安装并登录的 Codex。

Windows 双击 `start.cmd`，启动脚本会在缺少依赖时运行 `npm ci`，并重新构建前端。默认地址为 http://127.0.0.1:4317/。

也可以在项目目录运行：

```powershell
npm ci
npm run build
npm start
```

可选环境变量：

| 变量 | 用途 |
| --- | --- |
| `PORT` | HTTP 端口，默认 4317 |
| `CODEX_BIN` | Codex 可执行文件路径，默认自动查找 |
| `BRANCH_DATA_DIR` | 本机状态目录，默认项目下的 `data/` |
| `CODEX_STANDALONE=1` | 跳过桌面共享代理，直接使用独立 app-server |

## 使用

- 在左侧展开“项目与对话”，读取当前电脑的 Codex 项目和会话。
- 正文展示用户问题与最终回答；分析过程、任务状态和原始上下文在“详情”中查看。
- 输入续问时，左图即时出现草稿节点；选词追问时，从准确来源点显示预览分支。发送后自动同步真实节点和回答。
- 一个节点代表一轮问答。入口向下延伸，追问改变方向，普通续问沿原方向继续；实线表示通往当前问题的路径。
- 简图与详图可以切换，点击节点立即定位问答，中键拖动图面，拖动分隔线调整栏宽。
- 设置中可选择新对话项目目录、模型和推理强度；目录映射用于解析正文中的本地资源链接。

只读取本机可访问的真实 Codex 历史，不提供学习记录导入、导出或离线问答快照。Codex 不可访问时会显示错误，不使用旧快照代替。

## 本地数据与 Git

`data/` 仅用于本机分支关联、文本选区、阅读位置、任务恢复、设置及生成的协议文件。选区与任务可能包含问答上下文，因此整个目录均被 Git 忽略。账号凭证由 Codex 管理。

提交源码、测试、文档、`package.json` 和 `package-lock.json` 即可。`node_modules/`、`dist/`、数据库、日志、环境配置和压缩包已通过 `.gitignore` 排除。另一台电脑克隆后安装依赖，连接该电脑自己的 Codex。

## 开发与验证

```powershell
npm test
npm run build
```

- `npm test`：选区、持久化、任务队列、图布局及实时输入预览的自动化测试。
- `npm run build`：TypeScript 检查与 Vite 生产构建。
- `npm run probe`：只读检查本机 app-server 协议；输出可能含本机对话内容。
- `npm run test:live`：新建独立真实测试对话，检查发送、并行分叉、三级追问及去重，会使用模型额度。
- `node test/source-fork-live.mjs`：在上一项测试创建的对话中验证较早轮次分叉，不继承后续轮次。

代码结构与约定见 [开发说明](docs/DEVELOPMENT.md)。

## 连接边界

服务仅监听回环地址，并校验 Host、Origin 和会话令牌。本地文件只允许访问设置中指定的目录，Markdown 不执行原始 HTML。

优先尝试桌面共享 app-server，不可用时使用独立进程。独立进程无法与桌面实现跨进程原子互斥，请避免两端同时向同一对话发送消息。不同对话最多启动三个已确认活动任务；发送结果不确定时只暂停对应对话，不自动重复提交。

网页发起的任务采用只读沙箱、禁止命令网络访问，不自动批准提权或工具请求。桌面独有插件能力不保证继承。
