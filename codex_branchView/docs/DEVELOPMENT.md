# 开发说明

## 结构

| 路径 | 职责 |
| --- | --- |
| `src/main.tsx` | 会话与正文、选词、滚动、设置、SSE 订阅 |
| `src/graphPreviews.ts` | 草稿和待同步任务的临时节点 |
| `src/questionGraph.ts` | 图关系、布局与当前回溯路径 |
| `src/QuestionMap.tsx` | SVG、缩放、导航和中键拖动 |
| `src/presentation.ts` | 清理正文包装，区分最终回答与分析进度 |
| `server/index.mjs` | HTTP API、事件流、本地文件与启动检查 |
| `server/rpc.mjs` | 查找 Codex，连接 app-server，处理 RPC |
| `server/engine.mjs` | 实时历史读取、任务排队、恢复和中断 |
| `server/store.mjs` | 本机 SQLite 关联与状态；清理旧版快照 |
| `server/domain.mjs` | 选区验证、追问上下文、忙碌判断 |
| `server/desktop.mjs` | 只读解析本机项目及会话归属 |
| `test/` | 单元测试与显式执行的真实验收脚本 |

## 行为约定

1. 普通发送继续真实对话，选词追问创建真实 fork，且使用准确的来源轮次。
2. 节点使用真实 `threadId:turnId`。草稿没有真实 turnId，不可导航，不加入当前回答的实线路径；读取到真实轮次后自动替换。
3. 入口竖直向下，每次追问改变方向，普通续问严格共线。所有连接保持直线。
4. 当前问题到入口的路径为实线，其他为虚线；仅改变选中状态时不重排节点。
5. 来源无法读取时显示提示，不伪造连接。历史仅取自当前电脑的 Codex，不保存独立问答快照。
6. 发送结果不确定时继续核对，不自动重发；同一对话保持串行，其他对话可以继续。
7. SSE 重连补取状态；读取期间收到更新时再次读取，避免漏掉最终轮次。

## 验证方式

日常修改运行 `npm test` 和 `npm run build`。真实测试会创建本机 Codex 对话并消耗额度，按需显式执行；测试报告写入已忽略的 `data/`。

提交前检查 `git status --short`，确保数据库、登录信息、日志、截图中的私人对话以及模型生成的验收报告没有进入提交列表。
